## Extraction procedure

Keep modules internal until there is a second real consumer, an owner, a license decision and a versioning/test budget. First expose the smallest public API, remove application path aliases, parameterize only actual integration ports, declare style/provider requirements, and run contract tests from an independent harness. Preserve AGPL/third-party notices. Do not create packages, event buses, registries or universal controller factories just to complete a diagram.
