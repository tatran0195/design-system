# Adopted patterns and trade-offs

| Decision | Concrete problem / fit | Trade-off / why simpler is insufficient |
| --- | --- | --- |
| Feature-oriented modular monolith | An all-capabilities API barrel and technical folders obscure ownership. Existing monorepo, frameworks and backend stay. | More explicit files/imports; no independently versioned feature packages. A folder move without dependency rules would not isolate teams. |
| Named public facades + AST fitness functions | Cross-owner internal access/cycles otherwise reappear during AI-assisted changes. Rules cover static/dynamic/re-export edges, declared capability DAG, layers, duplicate/star public exports, missing imports and unreachable modules. | One existing parser is explicitly declared as a dev dependency; TS7 has no stable compiler AST API. Regex-only policy checks are insufficient for TSX/re-exports. Negative tests verify rejection, not just today's success. |
| Project/content/workspace entities | These concepts have independent editor/settings/project/reader consumers. Their query contracts must not require screen feature imports. | Keep only three meaningful entities. Wire DTOs remain Nibleaf integration types where mapping would add no meaning. An entity per DTO would add layers without ownership benefit. |
| Nibleaf integration seam + injected generic HTTP ports | Origin/locale/deployment policy previously lived inside generic transport and feature operations lived in global hooks. | Preserve explicit endpoint semantics and key identities. No dependency-injection container, universal service or new backend/auth implementation. |
| Split wire schemas | A 1,193-line namespace initialized unrelated schemas and conflated protocol domains. | Twenty-one cohesive schema partitions retain validation expressions and dependencies. Do not invent frontend domain models or rewrite backend rules to make imports easier. |
| Pure publishing model + lifecycle controller | Status/preflight ordering and editor revision/preview/debounce decisions were embedded in JSX/routes. | Pure helpers are easy to test; the authoring hook remains app-specific (RHF/Query/preview). A generic god hook/state-machine framework would hide important domain semantics. |
| Primitive browser preference adapter | Editor copied/persisted four browser preferences through repeated effects and unguarded storage access. | Decoder/encoder are explicit, native storage cleanup is centralized, denied storage has a local fallback. It deliberately excludes payloads, query caches and complex global state. |
| Two RHF presentations, one state owner | Nested compound array fields and controlled document/config values have different rendering needs. | Both use RHF/Zod; retain existing behaviors/tests rather than mechanically rewriting 100+ call sites into a new universal form framework. The misleading legacy `useForm` shim export was renamed `useFieldForm`. |
| Plain Markdown engine below lazy rich augmentation | Expanded dynamic-edge checking found facade → lazy rich → facade cycle. | Selector and shared renderer engine are separate; optional KaTeX/raw processors remain lazy. A cycle exception was not necessary. |
| Explicit server request-scope installation | Module-initialization fetch replacement hid request credential/IP behavior. | Entry now visibly installs a scoped, cleanup-aware adapter. It still wraps process fetch for legacy SDK consumers; replacing all of them with injected ports is a documented future integration task, not a hidden security guarantee. Public machine documents never inherit reader credentials. |
| Native Base UI composition | Native focus, keyboard, modal/layer ownership already work and are regression tested. | Keep this design contract; no custom focus stacks, overlay registries or global event bus. |
| Real lint cleanup + narrow protocol exception | Initial full lint had 163 existing errors, seven stale suppressions and one newly generated audit-artifact format issue. | Root rules/settings/tests are not relaxed. The only new narrow cookie exception documents guarded synchronous Paraglide wire compatibility; trusted nonce script rendering uses React's script children rather than an unsafe HTML prop. |
| No new extracted packages | Only app-local reuse is currently proven. | Catalog future extraction contracts/dependencies first; package/versioning overhead would be premature. |

## Deliberate, tested implementation changes

- Malformed error JSON now yields a predictable fallback/status instead of being asserted into a trusted error shape.
- Thirty supported GET query operations forward Query's cancellation signal; persistence mutations are not indiscriminately cancelled.
- A stale active-project preference now derives the visible first available project without silently writing storage during a data refresh. Explicit selection keeps the same storage key and persistence behavior.
- The copied duplicate reader CSS is emitted once; native shared styles/tokens remain unchanged.
- Accessibility fixes alter semantics/contrast, not routing, validation or backend requests: one main landmark per workspace, scoped/labeled navigation/outlines, and sufficient inherited-label/status contrast on measured default themes.
